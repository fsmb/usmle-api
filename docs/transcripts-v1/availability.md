# Transcript Availability

The USMLE API allows entities to access transcript information only for transcripts that are available to the entity. To view, or re-request, transcripts the following conditions must be met.

- The physician MUST HAVE previously submitted a transcript request through the [FSMB USMLE](https://usmle.fsmb.org) or [FCVS](https://myfcvs.fsmb.org) applications.
- The physician MUST HAVE selected the entity as a recipient.
- The transcript MUST NOT HAVE expired. See the [Exam Transcripts FAQ](https://www.fsmb.org/transcripts/transcripts-faq/) for more information on expiration of transcripts.

Once a physician has submitted a transcript request to FSMB it is generally available within minutes but may take up to 24 hours to appear. Refer to the [Exam Transcript FAQ](https://www.fsmb.org/transcripts/transcripts-faq/) for more information.
