# EcfmgInformation

ECFMG Information

| Name | Type | Required | Description |
| - | - | - | - |
| hasPartHistory | boolean | Yes | Indicates if ECFMG part history is available |
| partHistoryDescription | string (len: 500) | No | ECFMG part history description |
| hasLastCsa | boolean | Yes | Indicates if ECFMG last CSA is available |
| lastCsaDescription | string (len: 500) | No | ECFMG last CSA description |

*Note: Any fields marked as deprecated will be removed in a future version of the API. New code should not rely on these fields. Existing code should be updated to use alternative fields.*
